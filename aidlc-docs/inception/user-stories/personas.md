# 사용자 페르소나 (Personas)

이 프로젝트는 요구사항 분석 결정(Q1=A)에 따라 **2개 핵심 페르소나**로 정의합니다.

---

## Persona 1: 매장 고객 (Diner / Table Tablet User)

- **ID**: `P-CUSTOMER`
- **역할**: 매장 테이블에 착석하여 테이블 태블릿으로 직접 주문하는 손님
- **기술 숙련도**: 낮음~보통 — 스마트폰 앱 사용에 익숙하나 별도 학습 없이 즉시 사용 가능해야 함
- **사용 환경**: 테이블에 고정된 태블릿(브라우저 웹UI), 터치 인터페이스, 매장 내 조명/소음 환경
- **목표(Goals)**:
  - 대기 없이 즉시 주문 시작 (로그인 절차 인지 없음)
  - 메뉴를 쉽게 탐색하고 원하는 항목 선택
  - 주문 전 장바구니에서 수량/구성 조정
  - 주문 후 진행 상태(대기중/준비중/완료) 확인
- **불만/페인포인트(Pain Points)**:
  - 복잡한 로그인/인증 절차
  - 작은 버튼, 느린 반응, 헷갈리는 화면 이동
  - 이전 손님의 주문 내역이 섞여 보이는 것
- **관련 스토리**: US-C1 ~ US-C5

---

## Persona 2: 매장 관리자 / 운영자 (Store Admin / Operator)

- **ID**: `P-ADMIN`
- **역할**: 매장을 운영하며 주문을 모니터링·처리하고 테이블/메뉴를 관리하는 직원 또는 점주
- **기술 숙련도**: 보통 — 관리 도구 사용에 익숙하며 대시보드 기반 업무 가능
- **사용 환경**: 매장 카운터/주방 인근의 PC 또는 태블릿(브라우저 관리자 UI), 여러 테이블 동시 관리
- **목표(Goals)**:
  - 들어오는 주문을 실시간으로 놓치지 않고 확인 (2초 이내)
  - 테이블별 주문 현황과 총액을 한눈에 파악
  - 주문 상태 변경 및 잘못된 주문 직권 삭제
  - 손님 이용 완료 시 테이블 세션 정리(리셋) 및 과거 이력 보관
  - 메뉴 정보를 동적으로 등록/수정/삭제
  - 테이블 태블릿 최초 설정
- **불만/페인포인트(Pain Points)**:
  - 신규 주문을 제때 인지하지 못함
  - 테이블별 현황이 흩어져 보임
  - 세션 종료 후에도 이전 주문이 남아 혼선
  - 세션 만료(16시간)로 인한 갑작스러운 로그아웃
- **관련 스토리**: US-A1 ~ US-A7
